# gba

GBA emulator page for [yoshik.xyz/gba](https://yoshik.xyz/gba) — mGBA compiled to WebAssembly, running in the browser.

- Google login; ROMs stored privately in Google Drive, streamed through the backend only (never public).
- In-game saves + save states in MongoDB, keyed by the user's Google account `sub`.

Infrastructure setup only — app code lands later.
